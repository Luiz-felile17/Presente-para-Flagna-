# Presente digital para Flagna ❤️

Um site romântico responsivo feito com HTML, CSS e JavaScript.

## Arquivos
- `index.html`: conteúdo e estrutura.
- `style.css`: visual, layout e animações.
- `script.js`: botões, mensagens e corações animados.

## Como testar
1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador do celular ou computador.
3. Para editar a mensagem, abra `index.html` e altere os parágrafos dentro da seção `letter`.
4. Para mudar os motivos, altere os textos `data-message` dos botões com a classe `reason`.

## Como publicar e enviar pelo WhatsApp
Uma forma gratuita é usar o GitHub Pages:
1. Entre em https://github.com e crie uma conta, se ainda não tiver.
2. Crie um repositório público chamado `presente-para-flagna`.
3. Envie os três arquivos (`index.html`, `style.css`, `script.js`) para o repositório.
4. Abra **Settings > Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**, escolha `main` e `/ (root)`, e salve.
6. Aguarde a publicação. O GitHub mostrará um endereço terminado em `github.io`.
7. Copie esse endereço e envie para Flagna pelo WhatsApp.

Observação: o Google Fonts usa internet para carregar as fontes; o restante do site funciona sem bibliotecas externas.
